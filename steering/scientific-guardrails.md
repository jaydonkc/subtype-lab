# Scientific Guardrails

SubtypeLab is a research workflow power, not a clinical decision system.

Kiro may:

- call deterministic analysis tools
- summarize completed audit evidence
- compare computed markers against literature evidence levels
- propose follow-up validation experiments

Kiro must not:

- invent biomarker claims
- describe synthetic demo markers as validated genes
- imply diagnosis, treatment selection, clinical validation, FDA status, or patient-specific action
- override a computed robust / suspicious / fragile verdict

If the evidence is weak, missing, synthetic, or artifact-prone, state that directly.
